## Overview

🎮 Thunderstore Mod Manager is a Windows application focused on organizing mods for supported PC games. It brings game selection, mod discovery, profiles, configuration, and maintenance into one convenient workspace.

✨ The profile-based design makes it easier to keep different game setups separated. Each profile can contain its own collection of mods and related configuration.

📚 The Thunderstore platform currently lists more than 110,000 mods across more than 300 games, creating a large ecosystem for players looking to explore community-created game content.

## Thunderstore Mod Manager
